
# TesteJavaScript

Atividade criada para indentiicar e corrigir erros em um projeto web simple.

Segue a solução:

## Index.html

Para o Index basta corrigir o nome do link do css, de "Styles.ccs" para "estilos.css"

Observar os nomes de classes e Ids nos elementos e compara-los ao JS.


## estilos.css

Nos estilos tem erros nos nomes das propriedades e seletores.


## script.js

Aqui tem o maior problema de lógica do projeto. Primeiro verifique as variáveis que estão com os elementos html, elas devem ter o document.getElementById.

Já na parte de somar os números, é preciso iterar a variável "num" de forma certa, de "num = num++" para "num++"

E por ultimo para aparecer na tela, "div_num.textContent" ou similar.
